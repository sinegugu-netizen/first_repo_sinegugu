# A simple Invoice Generator that collects customer details, calculates total amounts, and exports invoices to Excel using Pandas.

### Features
- Interactive input for invoice data
- Automatic calculations:
     - 'Total Amount = Price * Quantity'
     - Auto-generated Date using 'datetime.now()'
- Clean printed invoice using string formatting ('.title()', .upper(), f-strings)
- **Phase 2:** Export to Pandas DataFrame and save as Excel file

### Tech Stack
- Python 3
- Pandas
- OpenPyXL
- Datetime
